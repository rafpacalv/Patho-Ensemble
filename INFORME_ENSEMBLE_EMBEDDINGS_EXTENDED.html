🔍 Problemas Encontrados y Resueltos

Error 1: Incompatibilidad Dimensional en predict_proba()

Problema: TabPFN y snapshot models retornaban (n,1) en lugar de (n,2) para binary classification.

# Fix aplicado:
if probs.ndim == 1:
    probs = np.column_stack([1 - probs.ravel(), probs.ravel()])
elif probs.ndim == 2 and probs.shape[1] == 1:
    probs = np.column_stack([1 - probs.ravel(), probs.ravel()])

Error 2: TabPFNClassifier API Change

Problema: TabPFNClassifier no aceptaba parámetros n_ensemble ni seed en la versión instalada.

# Fix aplicado:
model = self.TabPFNClassifier(device=self.device)
# Sin parámetros n_ensemble ni seed

Resultado: Ambos errores corregidos en v7. Todos los 8 modelos entrenados exitosamente.
