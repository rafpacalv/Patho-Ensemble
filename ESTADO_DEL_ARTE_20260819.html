Poder Estadístico (50 folds)

n_folds = 50 σ_diferencia ≈ 0.025 MDE (Minimum Detectable Effect) @ α=0.05, β=0.20: MDE ≈ ±0.016 en AUC Interpretación: ├─ Δ AUC < 0.016 → Indistinguible ├─ Δ AUC = 0.003 (FGE) → No detectable └─ Δ AUC = 0.010 (MLP) → Apenas detectable
💡 Conclusión Estadística: Con 50 folds, el MDE es ±0.016 en AUC. LogReg es óptima dentro de lo estadísticamente discernible. MLP Snapshot es alternativa borderline que podría brillar con más datos.
⚠️ Problemas Críticos Identificados

🔴 Crítico #1: TabPFN API Incompatibility

Error: TypeError: TabPFNClassifier.__init__() got unexpected keyword argument 'seed'

Impacto: Deep MLP Snapshot experiments no ejecutan

Solución: Remover seed parameter de meta_models.py

🔴 Crítico #2: SVM/KNN Reweighting Logic

Error: KeyError: 'macro-ovr-auc'

Impacto: SVM, KNN, Naive Bayes no funcionan con reweighting

Solución: Debug extracción de métricas en ensemble4.py

🔴 Crítico #3: Spatial/GNN Graph Construction

Error: ValueError: invalid lattice specification

Impacto: Rama spatial/GNN completamente no operativa

Solución: Asumir patches en secuencia lineal, no grid
