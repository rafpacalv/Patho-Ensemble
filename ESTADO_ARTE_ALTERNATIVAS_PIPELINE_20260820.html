🔍 1. Diagnóstico: El Pipeline Actual es 100% Fusión Tardía

1.1 Hallazgos de Explore Agents (Meta-learners × Pooling)

Dos agentes Explore descubrieron que ninguna de las 15 opciones de meta-learners en src/meta_models.py ni las 3 arquitecturas de pooling operan sobre pares de parches.

Meta-learners (9 opciones en ensemble4.py):

  • LogisticRegression, RandomForest, GradientBoosting, SVM, KNN, Naive Bayes (sklearn)
  • LightGBM, TabPFN, MLP (custom)

Arquitecturas de pooling (3 en train_abmil.py):

  • ABMIL (gated attention, línea 42–48 de train_abmil.py)
  • SpatialABMIL (variantes smooth/sage_bn/sage)
  • MultiHeadGatedAttention (experimental)

Dato clave: Todos operan sobre vectores ya colapsados a nivel de slide (probabilidad logit/embedding-512 posterior a softmax), generados por el ABMIL de cada modelo de forma independiente. El desacuerdo inter-modelo nunca es resuelto a granularidad de parche.

⭐ 2. Alternativa Recomendada: Fusión Temprana

2.1 Mecánica

Para cada slide:
  1. Carga embeddings de ctranspath[768] y virchow_v1[2560] (mismas coords)
  2. Concatena row-wise: [768] ⊕ [2560] → [3328]
  3. Entrena un ABMIL único sobre el tensor concatenado
  4. Atención puede ahora resolver desacuerdo inter-modelo LOCALMENTE
  5. Combina resultado con uni_v2 vía stacking

2.2 Coste de Parámetros

La primera capa nn.Linear(in_dim, 512) de ABMIL:

Escenario in_dim Parámetros Aumento
Mono-modelo (ej. ctranspath) 768 ≈ 394K Baseline
Mono-modelo (virchow_v1) 2560 ≈ 1.31M +3.3× baseline
Fusión temprana 3328 ≈ 1.71M +1.3× virchow

Evaluación: El aumento es modesto. La regularización implícita (dropout 0.25, early stopping) ya sobrevive al salto virchow_v1; el +0.4M es manageable.

📋 3. Protocolo de Validación

3.1 Fase 1: Piloto de 5 Folds (En Curso)

python src/ensemble5.py \
    --work_dir /home/JKP6679/Patho-Ensemble/PARADIS/datos/patches \
    --train_source cptac_brca \
    --tissue_patching 20x_224px_0px_overlap \
    --task_name TP53_mutation \
    --fuse_models ctranspath virchow_v1 \
    --other_model uni_v2 \
    --fold_start 0 --fold_end 4 \
    --epochs 100 --meta_model logreg

Criterio de señal:

  • ✅ Positivo (Δ AUC_mean > 0) → escalar a 50 folds + Holm-Bonferroni
  • ✅ Neutro (desv. estándar > |Δ|) → escalar a 50 folds
  • ❌ Negativo (Δ AUC_mean < -0.01) → cierre, documentar como intento #8

3.2 Fase 2: Escala a 50 Folds (Condicional)

Si Fase 1 da señal +/=, entrenar folds 0–49 y realizar análisis pareado con Holm-Bonferroni.
